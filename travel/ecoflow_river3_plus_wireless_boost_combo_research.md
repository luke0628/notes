## 一、完整技术规格 (Full Specs)

### 主机 (Main Unit)
| 参数 | 数值 |
|------|------|
| **电池容量** | 286Wh（可扩展至858Wh） |
| **电池类型** | LiFePO4（磷酸铁锂），3000次循环至80% |
| **额定输出功率** | 600W（持续） |
| **峰值输出（X-Boost）** | 1200W（注：评测认为此数字有夸大） |
| **AC充电速度** | 360W X-Stream快充，0-100%约1小时 |
| **太阳能输入** | 220W（XT60接口），0-100%约1.5小时 |
| **车载充电** | 12V点烟器接口 |
| **UPS切换时间** | <10ms（专业级） |
| **噪音** | <30 dB（超静音） |
| **重量** | 约10.4-10.6磅（约4.7-4.8千克） |
| **尺寸** | 约9.2 × 8.8 × 5.7 英寸（约23.4 × 22.4 × 14.5 cm） |
| **保修** | 主机5年，移动电源2年 |

### 输出端口 (Output Ports)
- **3× 120V AC插座**（1个前置，2个后置，均支持UPS）
- **1× 100W USB-C PD快充**
- **2× USB-A 接口**
- **1× 12V 车载点烟器输出**（额定<126W）
- **顶部15W Qi2无线充电板**
- **内置LED灯条**

### 可拆卸磁吸充电宝 (RAPID Magnetic Power Bank)
| 参数 | 数值 |
|------|------|
| **容量** | 5,000mAh |
| **磁吸无线输出** | 15W（MagSafe兼容） |
| **USB-C输入/输出** | 30W |
| **特色** | 折叠支架，可边充电边立起手机 |

## 二、Wireless Boost Combo 与普通版的区别

### 普通版 RIVER 3 Plus（独立版）
- 标准286Wh电源站
- 无顶部无线充电板
- 无可拆卸充电宝
- Amazon售价：**$259.00**

### Wireless Boost Combo 新增内容
1. **顶部内置15W Qi2无线充电板** — 比Qi1快2倍
2. **可拆卸5,000mAh RAPID磁吸充电宝** — MagSafe式连接
   - 放回顶部即可自动充电（支持直通充电）
   - 可用30W USB-C独立充电
   - 折叠支架设计
3. **Costco版本独有：含2个充电宝！**（比官网多1个）

### 售价对比
- 独立版（Amazon）：$259
- Wireless版（EcoFlow官网）：$409（已售罄）
- Wireless Boost Combo（Costco）：**$279.99**（含2个充电宝）

> 💡 **结论：Costco版本性价比极高，比官网便宜$130且多送一个充电宝。**

### 正面评价
- 可拆卸充电宝非常实用，露营时可随身带走充手机
- 超静音（<30dB），适合露营/卧室使用

- 5年保修在同级产品中最长
- 可扩展至858Wh，灵活性高
- Qi2 15W无线充电比Qi1快2倍

### 常见问题 ⚠️
| 问题 | 详情 | 严重程度 |
|------|------|----------|
| **电池自放电** | 有用户报告每天掉电10% | 🔴 中等 |
| **气味问题** | 负载时有异味（通常使用后消失） | 🟡 轻微 |
| **充电宝充电/发热** | 磁吸充电宝充电时发热 | 🟡 轻微 |
| **UPS可靠性** | 连接NAS设备时UPS模式不够稳定 | 🟡 特定场景 |
| **"不再支持"恐慌** | Reddit有帖子称"不再支持"，实际仍正常使用 | 🟢 误传 |
| **X-Boost夸大** | 1200W X-Boost被评测认为严重夸大 | 🟡 营销问题 |
| **仅支持特定充电宝** | 旧款EcoFlow充电宝不兼容顶部充电板 | 🟡 兼容性 |

### 适合的理由 ✅
| 特点 | 露营优势 |

| <30dB超静音 | 不打扰露营体验 |

| 12V车载输出 | 可给车载冰箱/气泵供电 |

| 需要给电动车充电 | 容量太小 |

### Yosemite露营评估

✅ 搭配220W太阳能板可实现无限循环
✅ Costco版本含2个充电宝，手机续航无忧
⚠️ 如果要用CPAP+其他设备，建议加购EB300扩展电池

| **App控制** | ✅ | ✅ | ✅ | ❌ |
| **上市状态** | 在售 | 已停产 | 已停产 | 在售 |
| **价格（Amazon）** | $259 | ~$249 | ~$249 | ~$199 |

### EcoFlow RIVER 3 Plus 核心优势
1. **充电速度最快** — AC 360W和太阳能220W均领先
2. **保修最长** — 5年 vs 多数竞品2年
3. **唯一可扩展** — 支持EB300/EB600扩展电池至858Wh
4. **UPS性能最强** — <10ms切换，竞品无此功能
5. **最安静** — <30dB

### EcoFlow RIVER 3 Plus 劣势
1. **价格偏高** — 同容量中较贵（但Costco版本性价比极高）
2. **重量偏重** — 比Jackery重约2磅
3. **X-Boost夸大** — 1200W峰值在实际中难以实现

### 对比总结
| 选哪个 | 理由 |
|--------|------|
| **EcoFlow R3+** | 需要快充、可扩展、长保修、UPS功能 |
| **BLUETTI EB3A** | 预算有限、需要无线充电（但已停产） |
| **Jackery 300+** | 追求最轻便（但已停产，且仅300W） |
| **VTOMAN 600X** | 最便宜、容量最大（但最重、充电最慢） |
